# 周反馈模板

每周每人提交一份反馈文档，记录本周对项目的思考、问题和建议。

## 文件命名

```
coordination/feedback/2026-W22_0525-0529/何天尧.md
coordination/feedback/2026-W22_0525-0529/吴凡.md
coordination/feedback/2026-W22_0525-0529/栗维鸿.md
```

## 提交方式

1. 在自己的分支上创建当周文件夹和文档
2. Push 到远程分支
3. 或直接在 main 分支提交（feedback 目录不影响代码）

## 时间节奏

- **周一~周四**：阅读项目文档 + 自主调研 + 整理思考
- **周五下班前**：提交本周反馈文档
- **负责人**：周末/下周一统一查看并回复
